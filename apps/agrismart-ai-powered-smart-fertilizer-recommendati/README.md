# AgriSmart — AI-Powered Smart Fertilizer Recommendation System

An intelligent agriculture platform that analyzes soil nutrients, crop information, weather conditions, and crop growth stage to recommend suitable fertilizers, application quantities, and timing.

Built with Mako Apps: a real Vite + React project stored in a Mako-managed
git repository. Run `npm install` (or pnpm/yarn) and `npm run dev` locally,
or edit it from Mako chat.
